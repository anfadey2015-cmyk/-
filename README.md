# Агрокалькулятор "ЗелСчёт"

Это программный продукт нужен для расчёта нужного количества удобрения для различных посевов с учётом информации поля

<img width="941" height="791" alt="изображение" src="https://github.com/user-attachments/assets/514071c2-2a95-463f-a692-40e73dfe52c0" />

Основной фнукционал:
- Расчёт количества нужного удобрения с учётом:
1. Область поля
2. Вид посева
3. Норма вноса удобрения
4. Информация про само поле (площадь, климат, тип почвы)
